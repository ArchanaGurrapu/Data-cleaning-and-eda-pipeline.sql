# SQL-Data-Cleaning-and-EDA-Project

Problem: Raw global layoff datasets were filled with duplicates, null values, and messy text columns, making accurate data analytics completely impossible.
Action:
• Cleaned duplicates by implementing ROW_NUMBER functions within a CTE frame.
• Standardized messy text and country strings using TRIM functions.
• Imputed missing industry cell values by writing database self-joins.
• Conducted Exploratory Data Analysis (EDA) using rolling total window functions.
Result: Converted a heavily flawed raw dataset into a 100% clean, structured relational database ready for executive reporting.
